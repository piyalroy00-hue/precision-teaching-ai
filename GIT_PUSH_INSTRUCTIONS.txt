================================================================================
GIT WORKFLOW - Push Changes to GitHub and Deploy to Render
================================================================================

STEP 1: Verify All Files Are Ready
-----------------------------------
You should have these new files in your project:
  ✓ Procfile
  ✓ render.yaml
  ✓ .env.example
  ✓ DEPLOYMENT.md
  ✓ DATABASE_SETUP.md
  ✓ RENDER_QUICKSTART.md
  ✓ RENDER_DEPLOYMENT_SUMMARY.md
  ✓ requirements.txt (updated with gunicorn)

STEP 2: Check Git Status
------------------------
Open PowerShell and run:

  cd "C:\Users\BRAINWARE UNIVERSITY\Desktop\SMR Project"
  git status

You should see the new files listed as "Untracked files" or "Changes to be committed"

STEP 3: Stage All Changes
--------------------------
  git add .

This adds all new and modified files to staging.

STEP 4: Verify Staged Changes
------------------------------
  git status

Should show something like:
  On branch main
  Changes to be committed:
    new file: Procfile
    new file: render.yaml
    new file: .env.example
    new file: DEPLOYMENT.md
    ... etc

STEP 5: Commit Changes
----------------------
  git commit -m "Add Render deployment configuration and documentation"

STEP 6: Push to GitHub (or GitLab/Gitea)
-----------------------------------------
  git push origin main

If you get an error about credentials, you may need to:
  1. Set up GitHub credentials
  2. Use GitHub Desktop instead
  3. Set up SSH keys

STEP 7: Verify on GitHub
-------------------------
1. Go to your GitHub repository online
2. Check that the new files appear in the commit history
3. Verify files are visible in the web interface

STEP 8: Deploy to Render
-------------------------
1. Go to https://render.com/dashboard
2. Click "New +" → "Web Service"
3. Select your GitHub repository
4. Follow the instructions in RENDER_QUICKSTART.md

================================================================================
IF GIT PUSH FAILS
================================================================================

Common issues:

1. "Authentication failed"
   - Set up GitHub credentials
   - Use: git config --global user.email "your@email.com"
   - Use: git config --global user.name "Your Name"

2. "Remote 'origin' not found"
   - Your project isn't a git repository or not linked to GitHub
   - Set up git first: git init
   - Add remote: git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO

3. "Branch 'main' not found"
   - Create main branch: git branch -m main
   - Or use current branch: git push origin HEAD:main

4. SSH key issues
   - Use HTTPS instead: git remote set-url origin https://github.com/...
